## Review checks

Mark each item and record details where necessary.

- [ ] The source was available and checked by the reviewer.
- [ ] Source title and attribution match the material reviewed.
- [ ] Edition/version and page/section are sufficient to locate the material again.
- [ ] The reference content matches the cited source within the intended scope.
- [ ] Terminology and translation are clear; uncertainty is recorded rather than inferred.
- [ ] Any medicine, potency, form, symptom, or relationship identifiers are unambiguous for this reference.
- [ ] The reference is general information and does not encode patient-specific treatment instructions.
- [ ] The reviewer considered whether a second independent review is required by clinic policy.
- [ ] The version history and prior reviewer attribution will remain preserved.
- [ ] Any known limitation, conflicting source, or missing information is recorded below.

- [ ] Rejected.

- [ ] Deferred pending additional source information or qualified review.
- [ ] Deactivated / withdrawn from current reference use.
